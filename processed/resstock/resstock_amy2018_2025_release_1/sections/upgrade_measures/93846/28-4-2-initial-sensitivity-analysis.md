## 4.2  Initial Sensitivity Analysis

To determine how the performance of load flexibility varies across the range of event durations and set point magnitudes in real-world smart demand response thermostat programs, we performed an initial sensitivity analysis using a small test run of 1,000 buildings across the United States. The range of inputs was parametrized across a set of 17 different upgrades, as shown in Table 6.
