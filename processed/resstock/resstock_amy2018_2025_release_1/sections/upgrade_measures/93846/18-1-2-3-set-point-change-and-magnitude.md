## 1.2.3  Set Point Change and Magnitude

Different durations of pre-peak load shifting and different set point offsets for load shifting or load shedding can be applied by HVAC load flexibility programs. For a mild impact on residents, a shorter on-peak duration (e.g., 2 hours) with a small set point offset during the on-peak hour (e.g., 2°F) can be used. In contrast, for the maximum load change, a longer pre-peak period (e.g., 4 hours) with larger set point adjustments, such as a low precooling set point (e.g., 60°F) and/or a high on-peak cooling set point (e.g., 80°F), may be applied.

Table 1 outlines the pre-peak and on-peak durations as well as the set point offsets used in existing smart thermostat programs. Typically, on-peak periods last 1 -4 hours, and the set point is adjusted by 1 -4°F during peak periods to align with residents ' comfort preferences. Load-shifting preheating or precooling strategies are not widely adopted in the current programs surveyed for this analysis. These findings broadly match the findings reported in a 2024 market overview of demand flexibility programs (Sean Murphy, 2024).

The appropriate pre-peak duration and set point offset depend on various factors, including a home ' s insulation quality, cooling system capacity, and weather conditions. Research suggests that pre-peak durations of 1 -4 hours and set point offsets of 2 to 6°F for preheating or precooling are effective strategies (German &amp; Hoeschele, 2014).
