## 3.1 Applicability

The goal of demand flexibility is to change the electric or gas load profile of the building in a meaningful way; therefore, this measure is applicable to all dwelling units with either a cooling system or a heating system. Although the measure shifts the load profile of the dwelling units with nonelectric heating during heating season, the change to the electric load profile is minimal because it only changes the fan or pump electricity consumption. For this reason, the heating load analysis in this document is focused on buildings with electric heating only.
