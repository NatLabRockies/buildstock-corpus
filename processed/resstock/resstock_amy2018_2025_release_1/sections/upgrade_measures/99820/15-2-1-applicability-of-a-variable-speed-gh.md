## 2.1  Applicability of a Variable-Speed GHP Measure

Using the same applicability criteria as the single-stage GHP and the stand-alone variable-speed compressor, the water-to-air vertical ground heat exchanger GHP upgrade measure applies to all dwellings with:

- Non-shared (in-unit) HVAC and any of the following heating fuels: electricity, natural gas, fuel oil, or propane
- Shared (across multiple units) HVAC and a building height of &lt;8 stories and any of the following heating fuels: electricity, natural gas, fuel oil, or propane
- Dwelling units with ducts
- Dwelling units with soil thermal conductivity greater than 0.8 Btu/hr-ft-°F.

With these applicability constraints, the measure upgrade applies to roughly 71% of the existing building stock. 6.4% of the residential units that receive the GHP upgrade lack existing space cooling systems in the baseline and therefore receive a central cooling system via the GHP.

From the previous work on this GHP model, applicability of this measure upgrade is based on ResStock housing characteristics that determine the available options and the options' details (Reyna, et al., 2025) (Maguire, et al., 2026). Specifically, the 'HVAC Heating Efficiency' characteristic in ResStock is used to apply each respective heat pump option. 'HVAC Has Ducts' describes the presence of ducts in the dwelling. 'Heating Type' describes the baseline heating fuel of the dwelling. 'HVAC Shared Efficiencies' describes the shared HVAC system of the dwelling, if applicable. 'Geometry Building Type Height' describes the height and building type of the dwelling. More information on the ResStock housing characteristics can be found in the ResStock Technical Reference Guide (Reyna, et al., 2025).
