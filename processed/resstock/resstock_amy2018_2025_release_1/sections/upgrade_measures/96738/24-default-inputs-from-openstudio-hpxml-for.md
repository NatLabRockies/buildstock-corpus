## Default Inputs from OpenStudio-HPXML for Infiltration Upgrade

The ResStock inputs in the table above are sent to OS-HPXML. Any values that are not specified by ResStock are calculated using the defaults in the BuildResidentialHPXML OpenStudio measure based on building characteristics. These characteristics include the building ' s floor area, number of stories, vintage, ceiling height, duct locations, foundation type, and climate zone. Other characteristics include stack effect, indoor-outdoor temperature difference, wind speed, and more. In multifamily and attached buildings, OS-HPXML assumes that some air leakage occurs between units rather than solely to the outside. To account for this, the software adjusts total infiltration based on the portion of the building envelope that is exposed to the exterior. More details of the infiltration model and default values can be found in the Alberta Air Infiltration Model (AIM-2) [16].
