## 6  Discussion

As shown in Section 5.3, analyzing results in isolation can suggest unfavorable impacts to peak demand.  This  occurs  because  the  measure  assumes  that  100%  of  the  units  adopt  EVs  and participate in the DF shift, which is not realistic. We model this measure in this way to maintain flexibility in the scenario analysis. However, users should blend results from this measure with the baseline or other measures in the desired proportion. For example, if we assume that only 25% of the dwelling units participate in DF but 100% of them will have an EV with an L2 charger, we can analyze a custom scenario. The weighted average of this scenario is shown in Figure 12, where we combine the results of this measure with an equivalent measure without DF in a 1:3 proportion to simulate a DF penetration level of 25%. We can see that when the DF penetration is reduced, the rebound peak is substantially reduced as well.

Another point to keep in mind when using the results of this measure is that the peak definitions are based on the 2050 Mid-case Cambium 2024 net load data, but we are applying these to the current residential sector building stock. This approach is meant to provide data for a DF potential in a future scenario and, as such, should be mixed with the baseline in the desired proportion to model that future scenario.

Figure 12. Daily residential electricity load shape for Colorado showing how a 25% DF penetration would reshape the load shape for winter (left) and summer (right). This measure ('EV + L2 Charger + DF') and two reference cases ('Baseline' and 'EV + L2 Charger') are represented, as well as a combination of this measure applied at 25% and the EV + L2 reference case applied at 75%.
