## 3.1  OpenStudio-HPXML Overview

The ResStock building stock energy model includes conditional probability distributions of building characteristics that represent the contiguous U.S. residential building stock. These distributions are sampled to create a synthetic stock, with each sample assigned an option for each characteristic for every dwelling unit to be simulated. ResStock utilizes the OpenStudio-HPXML workflow to translate these dwelling characteristics into building models that can be simulated with OpenStudio ®  and EnergyPlus ®  using an HPXML file. For reference, the state of the OpenStudio-HPXML repository when the ResStock 2025 Release 1 dataset was created can be found here.
