## 3.2  Duct Sealing and Insulation Upgrades

Each building characteristic assigned in ResStock is translated to OS-HPXML parameters via a file called options\_lookup.tsv. A measure upgrade is modeled as changes to specific building characteristics of a model defined using the baseline building stock characteristics. This section covers the technical details of the duct sealing and insulation upgrade changes in the ResStock workflow.
