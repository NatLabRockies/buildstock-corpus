## 2.1  Applicability

Using the same applicability criteria as the single-stage GHP, the two-stage compressor, water-to-air heat pump with a vertical ground heat exchanger upgrade measure applies to all dwellings with:

- Non-shared (in-unit) HVAC and any of the following heating fuels: electricity, natural gas, fuel oil, or propane
- Shared (across multiple units) HVAC and a building height of &lt;8 stories and any of the following heating fuels: electricity, natural gas, fuel oil, or propane
- Dwelling units with ducts
- Dwelling units with soil thermal conductivity greater than 0.8 Btu/hr-ft-°F.

With these applicability constraints, the measure upgrade applies to roughly 71% of the existing residential building stock. 6.4% of the residential units that receive the GHP upgrade lack existing space cooling systems in the baseline. Units that are excluded from this measure, as well as more details about GHP modeling and assumptions, are more fully described in the documentation for the single-stage GHP measure (Maguire et al. 2025).

Applicability of this measure upgrade is based on ResStock housing characteristics that determine the available options and the options' details (Reyna, et al., 2025). Specifically, the 'HVAC Heating Efficiency' characteristic in ResStock is used to apply each respective heat pump option. 'HVAC Has Ducts' describes the presence of ducts in the dwelling. 'Heating Type' describes the baseline heating fuel of the dwelling. 'HVAC Shared Efficiencies' describes the shared HVAC system of the dwelling, if applicable. 'Geometry Building Type Height' describes the height and building type of the dwelling. More information on the ResStock housing characteristics can be found in the ResStock Technical Reference Guide. 1
