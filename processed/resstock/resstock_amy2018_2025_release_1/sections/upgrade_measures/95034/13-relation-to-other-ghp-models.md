## Relation to Other GHP Models

Unless otherwise noted in this document, it is assumed that certain components of the two-stage GHP model overlap with (i.e., are the same as) single-stage model components. The following summarizes these overlapping components:

- Technology summary : The two-stage GHP works using the same general principles as the single-stage GHP, except that it has a two-stage compressor along with improved rated heating and cooling efficiency values.
- Applicability : The two-stage GHP applies to the same set of dwelling units as the single-stage GHP.
- Modeling approach : The two-stage GHP follows the same basic modeling approach as the single-stage GHP, except that the heat pump performance curves are updated, and a pump power energy management system (EMS) program is used. The model of the ground heat exchanger is identical for any GHP.

See the single-stage report (Maguire et al. 2025) for more detailed information about components that do not change between single-stage and two-stage GHPs. It is recommended to read that report first to fully understand the background technology, summary, assumptions, and discussions that were completed as part of this work.
