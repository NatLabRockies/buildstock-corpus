## 3.1  OpenStudio-HPXML Overview

The ResStock building stock energy model contains conditional probability distributions of building characteristics that are representative of the contiguous U.S. residential building stock. These are sampled to create a synthetic stock where each sample has an assigned option for each characteristic for each dwelling unit to be simulated. ResStock utilizes the OpenStudio-HPXML workflow to translate these dwelling characteristics into building models ready to be simulated via OpenStudio ® and EnergyPlus ®  through the use of an HPXML file. For reference, the state of the OpenStudio-HPXML repository when the ResStock 2024 Release 2 dataset was created can be found here. Assumptions about the attic floor insulation upgrades that are not explicitly defined in ResStock are taken care of in the BuildResidentialHPXML measure.
