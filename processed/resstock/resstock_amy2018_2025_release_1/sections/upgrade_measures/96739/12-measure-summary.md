## Measure Summary

| Measure Title                  | Attic Floor Insulation                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
|--------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Measure Definition             | This measure upgrades attic floor insulation in unfinished attics where the existing R- value falls at least R-10 value below the maximum level recommended by the IECC for each unit's climate zone. The post-retrofit R-value is set to reflect the maximum value recommended by code, while still aligning with outcomes observed in empirical studies. For example, while the IECC recommends an R-value range of R-49 to R-60 for climate zone 2, dwelling units in this zone are upgraded to R-60 to represent the upper bound of achievable performance. This approach ensures that the modeled retrofit captures both the energy savings potential of code-compliant upgrades and the levels typically achieved in field implementations. |
| Applica- bility                | This measure applied to all units that meet the following conditions: • The unit has an existing unconditioned and accessible attic • The existing attic floor insulation R-value is below the IECC-recommended level for the corresponding climate zone. With these applicability constraints, the measure upgrade applies to 42.9% of existing dwelling units.                                                                                                                                                                                                                                                                                                                                                                                  |
| Not Applicable                 | • This measure package will not apply to: Dwellings without existing attics • Dwellings with floor insulation R-value at the code requirement. These constraints exclude 57.1% of dwelling units from receiving this measure upgrade.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
