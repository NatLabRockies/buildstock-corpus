## 3.2  Attic Floor Insulation

In ResStock, building characteristics are translated to OS-HPXML parameters using the options\_lookup.tsv file. Measure upgrades, such as ceiling insulation or attic floor insulation for unfinished attics, are modeled as changes to baseline building characteristics. This section outlines the technical details of how ceiling insulation upgrades are implemented in the ResStock workflow.
