## Appendix B: Legacy OpenStudio-HPXML GHP Workflow and Assumptions

The original model for GHPs, which originated in BEopt over a decade ago, is still present in OpenStudio-HPXML. Since then, the code, modeling assumptions, and workflow have changed significantly as detailed previously. Following is some documentation existing assumptions still used in the current model around its ground domain modeling, heat pump assumptions, and soil property assumption.
