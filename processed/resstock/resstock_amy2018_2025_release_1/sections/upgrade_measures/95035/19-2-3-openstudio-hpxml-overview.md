## 2.3 OpenStudio-HPXML Overview

The ResStock building stock energy model contains conditional probability distributions of building characteristics that are representative of the contiguous U.S. residential building stock [7]. These are sampled to create a synthetic stock where each sample has an assigned option for each characteristic for each dwelling unit to be simulated. ResStock utilizes the OpenStudio-HPXML workflow to translate these dwelling characteristics into building models ready to be simulated via OpenStudio and EnergyPlus through the use of an HPXML file. For reference, the state of the OpenStudio-HPXML repository when the ResStock 2025 Release 1 dataset was created can be found here. Assumptions about the GHP upgrades that are not explicitly defined in ResStock are taken care of in the BuildResidentialHPXML measure.

For information on how OpenStudio-HPXML handles controls in ResStock Dataset 2025 Release 1 see here, and for how it handles HVAC distribution see here. Additional details regarding applying the two-stage GHP measure are included in the relevant section of that measure document.
