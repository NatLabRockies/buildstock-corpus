## 3.2  HPWH Upgrade

In the model articulation step of the workflow, each building characteristic assigned in ResStock is translated to OpenStudio-HPXML parameters. An OpenStudio-HPXML default value is used when there is no input from ResStock for a required field. A measure upgrade is modeled as changes to specific building characteristics of a model articulated using the baseline building stock characteristics. This section will go over the technical details of HPWH upgrade changes in the ResStock workflow.
