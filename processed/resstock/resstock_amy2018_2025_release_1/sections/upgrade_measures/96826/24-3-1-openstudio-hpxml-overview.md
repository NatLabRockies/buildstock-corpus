## 3.1  OpenStudio-HPXML Overview

The ResStock building stock energy model contains conditional probability distributions of building characteristics that are representative of the U.S. residential building stock. These are sampled to create a synthetic stock where each sample has an assigned option for each characteristic for each dwelling unit to be simulated. ResStock utilizes the OpenStudio-HPXML workflow to translate these dwelling characteristics into building models ready to be simulated via OpenStudio and EnergyPlus through an HPXML file. For reference, OpenStudio-HPXML v1.10.0 was used to produce ResStock 2025 Release 1 dataset.
