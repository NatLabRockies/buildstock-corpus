## 2.1  Baseline Window Characteristics

In ResStock, the baseline window types come from the U.S. EIA 2020 RECS microdata, and the key performance data for each window type comes from NFRC (Reyna, et al., 2025). Window types are dependent on climate zone, poverty level, vintage, tenure, and building type. Table 7 shows the key performance values associated with each of the baseline window types. Notably, none of the baseline window types meet the modeled ENERGY STAR V7 performance characteristics for any of the climate zones.

Table 8 shows the prevalence of each window type in the baseline as a percentage of the national total number of dwelling units. Nationally, the most common window type is Double, Low-E, Non-Metal, Air, M-Gain at 22.4%, followed by Double, Clear, Metal, Air at 19%. Looking at the South-Central and Southern climates, single pane windows are more common. This is expected given the milder weather in those climates.
