## 1.2.3  Comparison of ENERGY STAR to Energy Code Requirements

In most places in the U.S., an energy code sets the minimum performance of new windows. For this upgrade, it is important that the modeled windows meet the energy code requirements for the locations they are installed.

To determine the minimum energy code performance by location, the methodology described in the 2024 NLR report Residential Facade Retrofits Modeling: Results and Documentation (Elaina Present, 2024) was followed. The code adoption status by state was updated as of July 2025, accessed from the International Code Council (ICC) website. For each county in the U.S., the ENERGY STAR and IECC climate zones were identified, and the required performance characteristics were assigned to each based on the IECC or state-specific code for the state where that county was located (International Code Council (ICC), 2025). For this exercise, no sub-state energy code requirements were considered.

The unique combinations of energy code minimum performance values, along with the number of counties and dwelling units with these requirements, are shown in Table 3. The most stringent requirement for each of the ENERGY STAR climate zones that applies to more than 2% of the dwelling units is highlighted. This will be used as the benchmark that the modeled ENERGY STAR windows must meet or exceed for each climate zone. The judgment not to base energy code minimum performance levels for each climate zone on requirements that apply to only a tiny percentage of dwellings in a handful of counties was based on the energy code requirement analysis not including individual county- or city-level energy code requirements or reviewing all individual state codes for custom modifications.
