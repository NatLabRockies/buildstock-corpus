| Measure Title | ENERGY STAR Version 7.0 Window Upgrade |
|---|---|
| Measure Definition | This upgrade measure replaces any existing windows with less than the performance level specified by ENERGY STAR Version 7.0 (V7) with windows meeting this performance level. The technology applied in this measure upgrade package is denoted in the ResStock options_lookup.tsv as the following, depending on the climate zone: • Windows 'EnergyStar, Northern' • Windows 'EnergyStar, North-Central' • Windows 'EnergyStar, South-Central' • Windows 'EnergyStar, Southern'. |
| Applicability | This measure applies to all dwellings with: • Windows less than the performance level specified by ENERGY STAR V7. This performance level varies by climate zone. With these applicability constraints, the measure upgrade applies to 100% of the existing dwelling units. |
| Not Applicable | This measure does not apply to dwelling units with the following: • Windows that already meet or exceed the performance level specified by ENERGY STAR V7. These constraints exclude 0% of the dwelling units from receiving this measure upgrade. |
