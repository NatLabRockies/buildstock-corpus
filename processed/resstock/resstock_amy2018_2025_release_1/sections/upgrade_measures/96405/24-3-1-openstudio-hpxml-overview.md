## 3.1  OpenStudio-HPXML Overview

The ResStock building stock energy model contains conditional probability distributions of building characteristics that are representative of the U.S. residential building stock (Reyna, et al., 2025). These are sampled to create a synthetic stock where each sampled dwelling unit has an assigned option for each characteristic. ResStock utilizes the OpenStudio-HPXML workflow to translate these dwelling characteristics into building models ready to be simulated via OpenStudio and EnergyPlus through the use of an HPXML file. For reference, the state of the OpenStudio-HPXML repository when the ResStock 2025 Release 1 dataset was created can be found here (NREL, 2025). Assumptions about the window modeling that are not explicitly defined in ResStock are handled by the BuildResidentialHPXML measure.
