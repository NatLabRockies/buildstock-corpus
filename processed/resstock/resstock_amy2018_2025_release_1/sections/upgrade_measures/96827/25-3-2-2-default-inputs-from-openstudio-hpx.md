## 3.2.2  Default Inputs From OpenStudio-HPXML for the High-Efficiency Gas Water Heater Upgrade

The ResStock inputs in Table 4 are sent to OpenStudio-HPXML. Any values that are not specified by ResStock are calculated using the defaults in the BuildResidentialHPXML OpenStudio measure. These details can also be found in the OpenStudio-HPXML documentation v1.10.0.

Table 5. HPXML Default Values for the High-Efficiency Condensing Natural Gas Tankless Water Heater

| HPXML Default Variable                   | Value                         | Units   | Notes                                                                                                                                                                                                                                                                                                              |
|------------------------------------------|-------------------------------|---------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Performance adjustment                   | 0.94                          |         | Multiplier on efficiency, typically to account for cycling                                                                                                                                                                                                                                                         |
| Is shared system                         | No                            |         | Whether it serves multiple units or a shared laundry room                                                                                                                                                                                                                                                          |
| Fraction domestic hot water load served  | Auto                          |         | Fraction of hot water load from fixtures is determined automatically                                                                                                                                                                                                                                               |
| Has flue or chimney in conditioned space | Depends on the heating system |         | (Atmospheric) flue vent is assumed to be shared between space heating and water heating. The flue vent remains when the (existing) fuel heater is in the conditioned space and has an Annual Fuel Utilization Efficiency (AFUE) or equivalent efficiency rating of <89%, even as water heating no longer needs it. |
| Number of bedrooms served                | N/A                           |         | Not applicable because it is only used if the water heater is a shared system                                                                                                                                                                                                                                      |
| Usage bin                                | Medium                        |         | Used for UEF                                                                                                                                                                                                                                                                                                       |
| Uses desuperheater                       | False                         |         |                                                                                                                                                                                                                                                                                                                    |
