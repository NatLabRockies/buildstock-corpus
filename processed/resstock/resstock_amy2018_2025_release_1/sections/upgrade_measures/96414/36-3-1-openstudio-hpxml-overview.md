## 3.1  OpenStudio-HPXML Overview

The ResStock building stock energy model contains conditional probability distributions of building characteristics that are representative of the U.S. residential building stock (Reyna, et al. 2025). These distributions are sampled to create a synthetic stock where each dwelling model in the stock has an assigned representative option for each characteristic. ResStock utilizes the OpenStudio-HPXML workflow to translate these dwelling characteristics into building models ready to be simulated via OpenStudio ®  and EnergyPlus ®  through the use of an HPXML file. For reference, the state of the OpenStudio-HPXML repository when the ResStock 2025 Release 1 dataset was created can be found here. Assumptions about the measure upgrades in a ResStock dataset release that are not explicitly defined in ResStock are taken care of in the BuildResidentialHPXML measure.

In the case of heating/cooling upgrades in ResStock Dataset 2025 Release 1, these assumptions are all HVAC-related. This documentation covers the calculations directly related to the dual fuel heat pump, but HVAC controls (e.g., setpoints, cycling) and HVAC distribution (e.g., airflow systems) are out of its scope. For information on how OpenStudio-HPXML handles controls in ResStock Dataset 2025 Release 1 see here and for how it handles distribution see here. The following subsections will go through the ResStock inputs and the defaults calculated by BuildResidentialHPXML for the heat pump upgrade discussed in this documentation. Most defaults highlighted from the BuildResidentialHPXML measure stem from the apply\_hvac(), apply\_hvac\_sizing(), and apply\_detailed\_performance\_data() methods found in OpenStudio-HPXML's hpxml\_defaults.rb file. Note: the defaults.rb file calls methods from various Ruby files within the directory it resides. See these Ruby files here.
