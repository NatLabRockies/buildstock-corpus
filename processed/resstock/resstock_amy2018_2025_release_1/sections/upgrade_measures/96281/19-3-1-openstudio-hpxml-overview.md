## 3.1  OpenStudio-HPXML Overview

The ResStock building stock energy model includes conditional probability distributions of building characteristics that represent the U.S. residential building stock (Reyna, Fontanini and Present, et al. 2024). These distributions are sampled to create a synthetic stock, with each sample an option for each characteristic. ResStock uses the OpenStudio-HPXML (OS-HPXML) workflow to translate these dwelling characteristics into building models that can be simulated via OpenStudio ®  and EnergyPlus ®  using an HPXML (Home Performance eXtensible Markup Language) file. The state of the OpenStudio-HPXML repository at the time the ResStock 2025 Release 1 dataset was created is available on the NLR ResStock Resources page on GitHub. 5
