## Measure Summary

| Measure Title      | EV Adoption With L2 Charging                                                                        |
|--------------------|-----------------------------------------------------------------------------------------------------|
| Measure Definition | This measure adds one EV to each occupied dwelling unit. With each EV, an L2 charger is also added. |
| Applicability      | This measure applies to all occupied dwelling units.                                                |
| Not Applicable     | This measure does not apply to vacant units.                                                        |
