## Measure Summary

| Measure Title      | EV Adoption With L1 Charging                                                                                                                               |
|--------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Measure Definition | This measure adds one EV to each occupied dwelling unit model that does not own an EV in the baseline scenario. With each EV, an L1 charger is also added. |
| Applicability      | This measure applies to all occupied dwelling units without EV ownership in the baseline scenario.                                                         |
| Not Applicable     | This measure does not apply to dwelling units with EV ownership or vacant units in the baseline scenario.                                                  |
