## BuildStock Query Repository
[buildstock-query](https://github.com/NatLabRockies/buildstock-query) is a Python library for querying datasets generated by ResStock and ComStock. Introductory tutorial videos can be found on the [NLR Learning BuildStock Analysis YouTube channel](https://www.youtube.com/watch?v=jmmAHsOZAp8&list=PLmIn8Hncs7bEYCZiHaoPSovoBrRGR-tRS&index=6).
