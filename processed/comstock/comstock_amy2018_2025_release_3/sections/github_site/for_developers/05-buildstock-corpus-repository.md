## BuildStock Corpus Repository
`buildstock-corpus` publishes ComStock's documentation in an AI-ready form: clean Markdown for every page on this website, the reference documentation, and every upgrade measure report, organized by dataset release. Every file opens with a provenance header naming its source, publication status, and corpus release tag, so an LLM or agent can read and cite it directly without scraping this site. Each corpus build is tagged and tags never move, so a citation resolves to the same text later. Agents should start with the repository's `AGENTS.md`, which explains how to read and cite the corpus, or with this site's [llms.txt](/llms.txt).
