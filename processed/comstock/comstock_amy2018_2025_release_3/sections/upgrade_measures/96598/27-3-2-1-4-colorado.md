## 3.2.1.4  Colorado

Colorado has no statewide building energy code, so we need to assume an appropriate ASHRAE 90.1 version for this measure. The Colorado Energy Office publishes a database of local code adoptions across the state [10]. From the map in Figure 4, Colorado's major cities (Denver, Colorado Springs, Fort Collins, and Pueblo), comply with IECC 2021 (or ASHRAE 90.1-2019). These major cities, which comprise is known as the Front Range Urban Corridor, comprise more than 85% of Colorado's population [22]. Many other mountain towns in the western part of the state also follow IECC 2021; therefore, we assume ASHRAE 90.1-2019 for the state of Colorado, with the understanding that a small fraction of the buildings in more rural parts of the state might be lagging this code level.
