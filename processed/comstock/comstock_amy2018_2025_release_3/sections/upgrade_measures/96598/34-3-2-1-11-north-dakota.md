## 3.2.1.11 North Dakota

North Dakota has no statewide building energy code, so we need to assume an appropriate ASHRAE 90.1 version for this measure. According to ACEEE, approximately 91% of the state's population lives in a jurisdiction that has adopted the North Dakota State Building Code, which includes the 2021 IECC [21]; therefore, we assume ASHRAE 90.1-2019 for the state of North Dakota.
