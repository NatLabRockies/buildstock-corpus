## 3.2.1.7  Kansas

Kansas has no statewide building energy code, so we need to assume an appropriate ASHRAE 90.1 version for this measure. According to ACEEE, the 2006 IECC became the applicable standard for new commercial structures, but it is not mandated [21]. In the absence of other information, we assume ASHRAE 90.1-2004 for the state of Kansas.
