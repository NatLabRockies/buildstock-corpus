## Upgrade Package Summary

| Package Title      | Comprehensive GHP Upgrade                                                                                                                                                                                                                                            |
|--------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Package Definition | This package replaces existing HVAC systems with one of three GHP-based systems in applicable models. It is a combination of three upgrades (Hydronic GHP, Packaged GHP, and Console GHP), also documented in 2024 Release 1.                                        |
| Applicability      | This package is applicable to 80% of the stock floor area. For a package to be applicable, the model must meet the applicability criteria of one or more of the measures.                                                                                            |
|                    | Packaged Water-to-Air GHP: Models with gas-fired or electric resistance packaged rooftop systems or packaged variable air volume systems (PVAV). This measure is applicable to 56% of ComStock floor area.                                                           |
|                    | Central Hydronic Water-to-Water GHP: Models with central hydronic systems including variable air volume (VAV) systems and dedicated outdoor air systems (DOAS) that are served by a boiler and/or chiller. This measure is applicable to 13% of ComStock floor area. |
|                    | Console Water-to-Air GHP: Models with minimal or no ductwork, including packaged terminal units, baseboard electric, and gas unit heaters, as well as residential-style systems. This measure is applicable to 11% of ComStock floor area.                           |
| Not Applicable     | This package is not applicable to 20% of the stock floor area.                                                                                                                                                                                                       |
|                    | Packaged Water-to-Air GHP: Models that do not contain gas-fired or electric resistance packaged RTUs or PVAVs.                                                                                                                                                       |
|                    | Central Hydronic Water-to-Water GHP: Models that do not have hydronic distribution. In addition, this measure is not applicable to buildings with hot water baseboards or buildings served by district thermal energy systems.                                       |
|                    | Console Water-to-Air GHP: Models with ducted systems, including RTUs, PVAVs, and VAVs.                                                                                                                                                                               |
|                    | Not Applicable to Any Measure in Package: Models served by district energy systems, direct evaporative coolers, or VRFs.                                                                                                                                             |
