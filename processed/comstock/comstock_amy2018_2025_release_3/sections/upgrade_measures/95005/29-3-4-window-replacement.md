## 3.4 Window Replacement

The Window Replacement upgrade replaces the windows of a model with new windows with thermal and tinting properties that align with the properties specified in the Zero Energy Small/Medium Office AEDG (Table 6). The upgrade will first identify the existing window properties for each ComStock baseline model. In cases where the U-value (thermal transmittance) and/or SHGC underperform those specified in the AEDG, the windows will be replaced with AEDG-compliant windows.
