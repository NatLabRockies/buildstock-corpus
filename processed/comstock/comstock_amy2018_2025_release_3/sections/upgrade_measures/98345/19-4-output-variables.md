## 4  Output Variables

Table 3 includes a list of output variables that are calculated in ComStock. These variables are important for understanding the differences between buildings with and without the Fan SP Reset measure applied. These output variables can also be used for understanding the economics of the upgrade (e.g., return on investment) if cost information is available (i.e., material, labor, and maintenance costs for technology implementation).

Table 3. Output Variables Calculated From the Measure Application

| Variable Name                 | Description                                                                          |
|-------------------------------|--------------------------------------------------------------------------------------|
| SP_reset_applied              | SP reset applied (true) or not (false)                                               |
| air_system_vav_avg_flow_ratio | Average air flow ratio (air flow as a fraction of design airflow) across VAV systems |
