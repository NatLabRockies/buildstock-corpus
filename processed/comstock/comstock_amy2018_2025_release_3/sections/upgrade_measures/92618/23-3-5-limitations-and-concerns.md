## 3.5  Limitations and Concerns

The limitations and concerns for each measure scenario comprising this package can be found in the individual documentation for each respective measure. One key item to note for the package specifically is that sizing is constant from the baseline to measure case and, therefore, is not impacted by the reduced load from added roof insulation. Future work could investigate the impacts of resizing the HVAC as a result of measures that could impact load calculations.
