## 3.2.1 Objective Selection and Input Schedule

The emission reduction objective targets the predicted emission profile and sheds electric load to reduce resulting emissions from electric power generation. With the selected objective, by applying the method 'Dispatch Schedule Generation' described in End-Use Savings Shapes Measure Documentation: Dispatch Schedule Generation for Demand Flexibility Measures, a daily emission dispatch schedule will be generated and used as the input of this measure. Specifications of parameters for generating the peak schedule are defined in detail in the supplemental documentation. Specifically for the emission reduction objective, the daily dispatch windows are determined corresponding to the maximum aggregated predicted emissions within the window among multiple candidate windows that contain the peak emissions.
