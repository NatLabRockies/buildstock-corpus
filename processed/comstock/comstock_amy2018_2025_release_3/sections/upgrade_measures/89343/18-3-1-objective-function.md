## 3.1  Objective Function

Given the broad scope of demand flexibility, we provide multiple options for optimizing demand flexibility to a single objective. Currently supported objective options are:

- Building-level peak load reduction
- Grid-level peak load reduction

We also plan to include other objectives such as bill cost reduction and grid operating cost reduction in future development.
