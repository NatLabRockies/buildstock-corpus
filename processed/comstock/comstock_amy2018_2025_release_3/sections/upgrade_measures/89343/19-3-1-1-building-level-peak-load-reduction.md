## 3.1.1  Building-Level Peak Load Reduction Objective Function

The peak load reduction objective is based on building-level-not regional- or system-levelelectric load. With the load prediction methods described in Section 3.2, annual predicted (estimated from ComStock baseline model simulations) building electricity load profiles (35,040 15-min-interval values) are used to identify daily load peaks and associated peak windows when load should be dispatched to reduce demand.
