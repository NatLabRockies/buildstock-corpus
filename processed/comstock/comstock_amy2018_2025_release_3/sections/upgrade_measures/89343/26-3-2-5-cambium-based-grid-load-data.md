## 3.2.5  Cambium-Based Grid Load Data

Cambium's hourly load data are used to represent grid-level load profiles when grid-level peak load reduction is the demand flexibility objective. Determining the scenario of representative load data from the Cambium dataset includes considerations related to scenario, metric, and location type.
