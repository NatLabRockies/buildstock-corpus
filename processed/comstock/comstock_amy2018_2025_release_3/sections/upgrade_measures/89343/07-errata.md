## Errata

This report, originally published in May 2024, has been revised in November 2025 with the following changes.

1. Section 3, Modeling Approach, has been revised to add an alternative objective option of 'Grid-Level Peak Load Reduction'
- a. Section 3.1.2, Grid-Level Peak Load Reduction Objective Function, has been added to describe the new objective.
- b. Section 3.2.5, Cambium-Based Grid Load Data, has been added to explain the method of extracting grid-level load data from the Cambium dataset.
- c. Section 3.4, Limitations and Concerns, has been revised to include discussion on the new objective option.
2. The Executive Summary also received minor updates accordingly.
