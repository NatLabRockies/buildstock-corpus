## 4  Output Variables

Table 2 includes a list of output variables that are calculated in ComStock. These variables are important in terms of understanding the differences between buildings with and without the single-zone VAV measure applied. These output variables can also be used for understanding the economics of the upgrade (e.g., return on investment) if cost information (i.e., material, labor, and maintenance costs for technology implementation) is available.

Table 2. Output Variables Calculated From the Measure Application

| Variable Name                                           | Description                                                                                                                                                            |
|---------------------------------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| fan_air_mass_flow_rate                                  | A distribution or average of this variable can help confirm that airflow at the supply fan is modulating.                                                              |
| heating_coil_heating energy cooling_coil_cooling_energy | Coil heating and cooling energy will be used as proxies to determine the heating or cooling status of the unit, and thus, the expected airflow.                        |
| air_system_outdoor_air_economizer_status                | A distribution or average of this variable can help confirm that the economizer is operating.                                                                          |
| air_system_outdoor_air_mass_flow_rate us                | An average or distribution of this variable can help confirm that DCV is operating as expected.                                                                        |
| count_air_loops_DCV_pre                                 | Number of air loops with DCV before the measure is applied.                                                                                                            |
| count_air_loops_economizing_pre                         | Number of air loops with economizing before the measure is applied.                                                                                                    |
| count_air_loops_DCV_post                                | Number of air loops with DCV after the measure is applied.                                                                                                             |
| count_air_loops_economizing_post                        | Number of air loops with economizing after the measure is applied.                                                                                                     |
| fan_electric_power                                      | The maximum value of this variable will be used to infer the design power draw of the fan. This can be used to estimate the cost of the VFD required for the retrofit. |
