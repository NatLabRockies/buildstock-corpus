## 4  Output Variables

Table 13 includes a list of output variables that are provided by ComStock. These variables are important to understand the differences between buildings with and without the Comprehensive GHP + High Efficiency Envelope package applied. Additionally, these output variables can be used for understanding the economics (e.g., return on investment) of the upgrade if cost information (i.e., material, labor, and maintenance cost for technology implementation) is available.

Table 13. Output Variables Calculated From the Measure Application

| Upgrade                  | Variable Name                             | Description                                                                           |
|--------------------------|-------------------------------------------|---------------------------------------------------------------------------------------|
| GHP Measures             | Ground heat exchanger borehole depth      | Borehole depth calculated from GHEDesigner (feet)                                     |
| GHP Measures             | Ground heat exchanger design flow rate    | Ground heat exchanger flow rate (cubic feet per minute)                               |
| GHP Measures             | Ground heat exchanger number of boreholes | Number of boreholes calculated from GHEDesigner                                       |
| GHP Measures             | WA HP Cooling Capacity                    | Water-to-air heat pump cooling capacity (Watts)                                       |
| GHP Measures             | WA HP Heating Capacity                    | Water-to-air heat pump heating capacity (Watts)                                       |
| GHP Measures             | WA HP Cooling Average COP                 | Water-to-air heat pump cooling coefficient of performance                             |
| GHP Measures             | WA HP Heating Average COP                 | Water-to-air heat pump heating coefficient of performance                             |
| GHP Measures             | Heat Pump Cooling Average COP             | Water-to-water heat pump cooling coefficient of performance                           |
| GHP Measures             | Heat Pump Heating Average COP             | Water-to-water heat pump heating coefficient of performance                           |
| Replacement              | Window-to-Wall Ratio                      | Ratio of window area to exterior wall area for the building model.                    |
| Replacement              | Window Type                               | Name of window construction type, as described in Table 2.                            |
| Replacement              | Average Window SHGC                       | Average SHGC of all the windows in the building model.                                |
| Replacement              | Average Window U-Value                    | Average thermal conductance of all the windows in the building model (Btu/hr ft 2 F). |
| Replacement              | Window Area                               | Total window area replaced by the upgrade (ft 2 ).                                    |
| Exterior Wall Insulation | Target R-value                            | Target insulation R-value based on climate zone (ft 2 -hr-R/Btu).                     |
| Exterior Wall Insulation | Insulation R-value per Inch               | XPS R-value per inch (hr ft 2 R/Btu per inch).                                        |
| Exterior Wall Insulation | Required Insulation Thickness             | Insulation thickness required to meet target R- value (in.).                          |

| Upgrade    | Variable Name                                     | Description                                                                                                                                                                        |
|------------|---------------------------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|            | Exterior Wall Insulation Area                     | Area of insulation added (ft 2 ).                                                                                                                                                  |
|            | Energy Code Followed During Last Roof Replacement | The energy code followed during the last roof replacement (or installation) for a building model, which dictates the roof performance properties for the ComStock baseline models. |
| Insulation | Average Roof Absorptance                          | The average absorptance of all roof surfaces for a building model.                                                                                                                 |
| Roof       | Average Roof U-Value                              | The average thermal conductivity of all roof surfaces for a building model (Btu/hr ft 2 F).                                                                                        |
|            | Roof Area                                         | The exterior roof area for a building model (ft 2 ).                                                                                                                               |
| Lighting   | Initial Lighting Power                            | Initial power by lighting technology (W)                                                                                                                                           |
| Lighting   | Initial LPD                                       | Average building LPD before upgrade is applied (W/ft 2 )                                                                                                                           |
| Lighting   | Final Lighting Generation                         | Lighting generation after upgrade is applied (should be Generation 5 if upgrade is applicable)                                                                                     |
| Lighting   | Final Lighting Power                              | Final lighting power by technology (W)                                                                                                                                             |
| Lighting   | Final LPD                                         | Average building LPD after upgrade is applied (W/ft 2 )                                                                                                                            |
