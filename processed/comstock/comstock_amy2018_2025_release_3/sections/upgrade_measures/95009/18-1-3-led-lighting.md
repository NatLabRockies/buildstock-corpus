## 1.3 LED Lighting

LED lighting is now the most common technology in new and retrofit interior lighting systems. Most lighting in commercial buildings is currently in the form of linear fluorescents and fluorescent troffer-style luminaires. There are direct one-to-one LED linear lamp replacements, as well as LED troffers. This measure does not distinguish between lamp and luminaire replacements. Additionally, this measure does not make any changes to the lighting controls in a building.

This upgrade package includes the LED Lighting measure, which replaces all non-LED lighting in a building with Generation 5 LEDs. Some buildings in the stock may not receive this measure if the building already has LED Lighting. For more details about the measure, reference the individual measure documentation: LED Lighting.
