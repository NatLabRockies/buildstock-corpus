## 3.2  Technology Specifics

This report is a slight modification to the Variable Refrigerant Flow with Heat Recovery and Dedicated Outdoor Air System measure from Commercial End-Use Savings Shapes 2023 Release 2, allowing 25% upsizing (or 125% from the original size) for buildings in heatingdominant regions. Because it shares much of the same information described in the previous documentation, the following sections highlight major differences and some key information that are worth repeating for VRF systems. All details regarding the DOAS can be found in the previous documentation.
