## 3.2.2  Heating Performance Modeling

The RTUs considered as upgrades in this study will use the same heating fuel that is already used in the existing building. Thus, if the building currently uses gas for space heating, the upgraded RTU will be equipped with a gas furnace (with typical ~80% efficiency). If the building uses electricity for space heating, the RTU will include electric resistance heating. Refer to the ComStock Reference Documentation for more details on how heating fuel is determined in the ComStock baseline [10].
