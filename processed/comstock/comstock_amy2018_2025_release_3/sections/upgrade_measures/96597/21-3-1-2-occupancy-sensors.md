## 3.1.2  Occupancy Sensors

Applicability for occupancy sensors is determined based on ASHRAE 90.1-2019 Table G3.7 Performance Rating Method Lighting Power Density Allowances and Occupancy Sensor Reductions Using the Space-by-Space Method [11]. This table defines a percent LPD reduction for common space types to represent the effects of occupancy sensors. Hence, occupancy controls are applied to a model on a space-by-space basis. The specifics of this methodology will be discussed in more detail in subsequent sections. In total, occupancy controls were applied to at least one space in 100% of models.
