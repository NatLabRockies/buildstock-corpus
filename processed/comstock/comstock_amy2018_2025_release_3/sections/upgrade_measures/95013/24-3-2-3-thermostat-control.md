## 3.2.3  Thermostat Control

The Thermostat Control for Load Shedding in Large Offices upgrade applies heating and cooling temperature set point offsets (setbacks) on applicable thermostats in models to reduce the heating and cooling load during the peak windows. Following every peak window, the upgrade applies a rebound period for set points to ramp back to the original values to mitigate the rebound (snapback) effect. This gradual restoration of the set point reduces the potential of creating a new peak load with immediate restoration, which was observed in simulation tests applying thermostat adjustment for peak demand periods.
