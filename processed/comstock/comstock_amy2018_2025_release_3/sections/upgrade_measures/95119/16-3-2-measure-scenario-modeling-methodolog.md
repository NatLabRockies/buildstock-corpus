## 3.2  Measure Scenario Modeling Methodology

In this measure scenario, existing gas-fired or electric resistance RTUs are replaced with HPRTUs modeled to align with typical standard performance HP-RTUs on the market today. The key performance metrics are largely based on NREL laboratory testing of a 7.5-ton 'standard performance' HP-RTU. The application of this data, and other key assumptions, are described in this section.
